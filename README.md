# Brand Report｜品牌与市场洞察 Skill

把品牌研究从“搜一堆资料、最后写一篇报告”，变成一条有阶段产物、数据可追溯、团队能执行的工作流。

它将**市场洞察、SEO/GEO、电商与社媒数据**放在同一套研究框架里：先确认问题和 ClaudeBaby 数据覆盖，再整理 Excel、形成结论、拆成部门行动手册，最后交付深度报告与质检记录。

## 能用它做什么

- **市场洞察与出海评估**：比较目标市场、需求信号、竞品结构、价格带、进入机会和风险。
- **SEO/GEO 诊断**：整理关键词与搜索意图、页面和内容机会、可用的 AI 搜索可见性数据，形成网站/内容团队行动清单。
- **电商研究**：查看被支持平台和站点的商品、价格、销量/趋势、评论和卖家信息，识别产品与竞争机会。
- **社媒聆听与活动复盘**：研究品牌和品类讨论、用户反馈、内容表现、活动前后变化与可复用做法。
- **消费者洞察与竞品分析**：将评论、帖子、商品和搜索信号串成有证据的主题、差异和验证计划。
- **跨部门落地**：把研究结论拆成市场、品牌、内容、SEO/GEO、电商等团队的任务、指标、优先级和复盘节奏。

覆盖范围以当前 ClaudeBaby MCP 实际可用的平台、工具、站点、字段和时间窗为准。没有取到的数据会注明缺口，不会用猜测补齐。

## 每一步都有产出

| 阶段 | 你能看到的结果 |
|---|---|
| 研究范围 | 目标、市场、周期、竞品、纳入/排除维度与验收口径 |
| 数据源检查 | ClaudeBaby 工具/平台覆盖、查询条件、权限与字段状态 |
| 数据与分析 Excel | 原始记录索引、清洗数据、分母、公式、来源链接和覆盖说明 |
| 部门行动手册 | 任务、证据依据、负责人角色、优先级、KPI 与复盘时间 |
| 最终报告 | 默认 HTML 深度报告；需要时可转成其他格式 |
| 交付质检 | 数字一致性、数据边界、隐私检查、交付文件清单 |

通常交付 **HTML 报告 + Excel 工作簿 + 部门行动手册 + 质检记录**。用户只需要数据或快速判断时，Skill 会按任务范围裁剪交付，不为凑齐文件而制造内容。

## 数据来源

本 Skill 的外部数据接入**只使用 ClaudeBaby MCP**，用于支持市场/品类信号、SEO/GEO、电商和社媒研究。不会再用其他数据服务、MCP、爬虫或浏览器抓取补数。

每次任务先验证 ClaudeBaby 当前连接和实际覆盖；数据缺失、无权限、工具报错或没有命中时会如实标注。用户上传的表格可作为输入材料，但会单独注明来源。返回记录若带有原始平台链接，可在报告中用于回查；Skill 不会绕过 ClaudeBaby 直接采集。

使用前请在你的 Agent 中配置并授权 ClaudeBaby MCP。不要把 API Key 粘贴到聊天、仓库或报告中。

- “对比美国和澳大利亚市场的户外音箱机会，先确认可用数据，再交付 Excel、市场报告和各团队行动手册。”

- “检查我们网站的 SEO/GEO 问题，把 ClaudeBaby 能支持的数据列清楚，再输出给网站团队的优先级清单。”
- “分析这批电商 SKU 的价格和评论，找出适合重点运营的产品，并给运营团队一份可执行计划。”
- “复盘一次新品活动：看讨论变化、评论主题和竞品同期动作，报告里区分数据事实与推断。”

## 仓库内容

- `SKILL.md`：Agent 的执行说明、数据边界和状态机。
- `references/`：阶段流程、证据与 Excel/报告交付规范。
- 不附带客户数据、独立采集器或凭证配置；数据调用由 Agent 中已连接的 ClaudeBaby MCP 完成。

## 重要边界

- 数据覆盖、样本量和结论质量取决于 ClaudeBaby 当前工具权限和返回结果。
- 社媒样本不等于总体市场份额；估算、抽样和缺失数据必须明确标识。
- Skill 不承诺自动登录、发布、购买、投放或接入客户店铺。
- 默认只发布通用 Skill 文档，不包含客户报告、私有数据、账号凭证或 API Key。
