# 数据与证据规范

## 单一外部数据接入

外部结构化数据只通过 ClaudeBaby MCP。每次执行先确认当前工具和字段覆盖，不能根据旧版本工具清单推定当前能力。若 ClaudeBaby 没有相应字段、平台、市场或历史窗口，记录缺口，不从其他服务、MCP、网站、搜索引擎、爬虫或浏览器补抓。

用户提供的文件、表格和访谈属于“用户提供材料”，需保留其来源与时间，不要标为 ClaudeBaby 数据。人工输入的商业假设、成本或销售目标要标为“用户假设/待验证”。

## 每条数据的最少字段

- 数据域、平台/站点、查询条件或对象
- 指标名、值、单位、分母和计算方式
- 采集时间、内容/交易时间及时间窗
- 样本量、去重方式、分页或截断状态
- ClaudeBaby 工具返回状态；失败、空结果和未授权分开标记
- 原始记录定位或来源链接（若返回）
- 数据限制和后续需要的人工核验

## 证据状态

| 状态 | 解释 | 报告表达 |
|---|---|---|
| 实测记录 | ClaudeBaby 本次返回具体记录/指标 | 报告数值及采集范围 |
| 计算结果 | 用本次原始记录按明示公式计算 | 报告公式、分母和输入数据 |
| 估计/代理指标 | ClaudeBaby 返回估计值或代理指标 | 明确标记“估计/代理”，说明不可替代什么 |
| 假设 | 用户或分析人员提出、尚未由样本验证 | 作为验证假设，不写成事实 |
| 未覆盖 | 当前工具或字段未提供 | 留空并说明结论边界 |
| 未授权 | 账号权限/访问权限不足 | 明确标注权限缺口 |
| 取数失败 | 工具错误、超时、上游不可用 | 记为错误，不能当作零数据 |
| 本次无命中 | 请求成功但没有结果 | 标注查询条件与范围，不推断整体需求为零 |

## 比较纪律

比较价格、销量、互动、关键词和地区时，要检查站点、时间、币种、促销、产品变体、样本范围和指标定义是否可比。不可比时分开陈列。百分比要有分子、分母和时间窗；变化率缺历史基期时不计算。

报告引用仅使用 ClaudeBaby 返回的来源链接或用户提供材料中的链接。引用用于读者回查，不授权 Agent 绕过 ClaudeBaby 直接抓取页面。
