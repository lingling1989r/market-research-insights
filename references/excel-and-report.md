# Excel、行动手册与报告 QA

## 工作簿最低结构

按项目选择相关工作表，避免不适用的空白 sheet：

1. `结论与行动`：关键发现、优先级、证据状态和下一步。
2. `范围与覆盖`：研究范围、ClaudeBaby 查询/平台/市场/时间窗、状态和缺口。
3. `原始数据索引`：记录 ID、核心字段、时间、来源链接、原始响应定位。
4. `市场与竞品`：细分、竞品、产品/渠道/价格维度及比较限制。
5. `SEO_GEO`：实际获取到的关键词、页面或可见性指标。
6. `电商`：实际获取到的商品、站点、价格、销量/趋势、评论和样本。
7. `社媒与VOC`：实际获取到的帖子、反馈、主题、互动和时间范围。
8. `部门行动`：任务、证据、责任角色、优先级、KPI、日期和复盘。
9. `口径与质检`：字段定义、公式、缺失状态和验收结果。

只有实际涉及的数据域才生成对应 sheet。无数据不要填 0；缺失状态写成明确文本。冻结首行、启用筛选、列名清晰，日期/币种/单位统一格式。

## 部门行动手册

行动项使用以下字段：`发现ID`、`发现摘要`、`证据/数据链接`、`行动`、`目标部门`、`负责人角色`、`优先级`、`计划时间`、`KPI`、`依赖`、`复盘日期`、`状态`。行动手册先写部门目标，再列行动清单与依据；不要用泛化建议代替明确动作。

## 报告 QA 清单

- 报告、Excel 和行动手册使用同一研究范围和口径。
- 每项重要数字都有单位、分母、时间窗、状态和数据定位。
- 报告图表由工作簿或同一结构化数据生成，不能手绘不明来源的数值。
- 明确区分市场规模、平台样本、社媒声量、搜索需求、销量和收入；不能相互替代。
- 结论同时呈现反例、主要限制和需要验证的假设。
- ClaudeBaby 没有提供的数据域已标为缺口，没有偷偷从外部补数。
- 文件中不含 API Key、MCP URL、Authorization header、Cookie、个人账号和客户私有数据。
- Excel 可打开，公式可复算；最终报告已渲染检查；清单中的每份文件都存在。
